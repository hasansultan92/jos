        1. What is the purpose of having an individual handler function for each exception/interrupt? 
        (i.e., if all exceptions/interrupts were delivered to the same handler, what feature that 
        exists in the current implementation could not be provided?)

        The purpose of having individual handler functions for each exception/interrupt is to allows
        different privelege level checks and error code handling. For example, some interrupts push
        error codes onto the stack while others do not. Having seperate handlers allows for us to 
        define which interrupts push error codes onto the stack and which do not. Additionally, having
        seperate handlers allows the kernel to enforce different privelege levels. For example system 
        calls (syscall) are invoked from user mode (ring 3) and other interrupts can only be invoked
        from kernel mode (ring 0).
